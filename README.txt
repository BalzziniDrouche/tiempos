Tiempos: установка как приложения

1. Выложи содержимое этой папки на любой HTTPS-хостинг (GitHub Pages, Netlify Drop, Cloudflare Pages, свой сервер).
2. Открой адрес на телефоне или компьютере.
   Chrome / Edge / Android: меню → «Установить приложение» (или «Добавить на главный экран»).
   iPhone (Safari): «Поделиться» → «На экран Домой».
3. После первого открытия приложение работает без интернета. Прогресс хранится на устройстве.

Если хостинга нет, используй один файл tiempos.html: его можно открыть двойным щелчком на компьютере
или с телефона из файлов. Он тоже работает без интернета.
